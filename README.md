# HEWN releases

Installers and automatic updates for **HEWN**, proof that a human made the music.

- **Download:** the newest `HEWN-x.y.z.dmg` under [Releases](../../releases/latest)
  (macOS 13+, Apple Silicon). Signed and notarized by Apple.
- Installed copies of HEWN update themselves from here. Every update is signed
  with HEWN's update key and checked by the app before it installs.
