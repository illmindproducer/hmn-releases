# HMN releases

Installers and automatic updates for **HMN (Human Made Notary)**, proof that a
human made the music.

- **Download:** the newest `HMN-x.y.z.dmg` under [Releases](../../releases/latest)
  (macOS 13+, Apple Silicon). Signed and notarized by Apple.
- Installed copies of HMN update themselves from here. Every update is signed
  with HMN's update key and checked by the app before it installs.
- Versions up to 0.3.2 were released under the product's earlier name, HEWN.
